# PhysioPipe: Reproducible 'targets' Pipelines for Physiological Signal Analysis

A collection of reusable 'targets' target factories for the Physio
ecosystem: drop-in pipelines for the standard single-modality analyses
(ECG heart-rate variability, EEG band power, EMG amplitude/fatigue, EDA
skin conductance) plus multi-record cohort branching and Quarto
reporting. Each factory returns a list of targets so a whole
reproducible '\_targets.R' is a couple of lines, with incremental
re-runs and byte-level provenance.
