# Read a WFDB record (by companion files or base) into a PhysioExperiment

Read a WFDB record (by companion files or base) into a PhysioExperiment

## Usage

``` r
pp_ecg_read(record)
```

## Arguments

- record:

  Either the companion files (`c(".dat", ".hea")`) or a single record
  base path (no extension).

## Value

A `PhysioExperiment`.
